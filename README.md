# 🎸 GrimLanding

Лендінг для рок-групи. На сайті представлена інформація про історію гурту, контактні дані та можливість придбати квитки на найближчі концерти.

---

## 🛠 Технології

- **Vite** — збірник проєкту
- **Sass** — препроцесор стилів
- **PostCSS** — обробка CSS
- **Swiper** — слайдер/карусель

---

## 📋 Вимоги

Перед запуском переконайтеся, що на вашому комп'ютері встановлено:

- [Node.js](https://nodejs.org/) версії **18** або вище
- **npm** (входить до складу Node.js)

Перевірити версії можна командами:

```bash
node -v
npm -v
```

---

## 🚀 Запуск проєкту

### 1. Розпакуйте архів

Розпакуйте завантажений архів у зручну папку.

### 2. Відкрийте термінал у папці проєкту

Перейдіть у папку з проєктом:

```bash
cd grimlanding
```

### 3. Встановіть залежності

```bash
npm install
```

### 4. Запустіть сервер розробки

```bash
npm run dev
```

Після запуску в терміналі з'явиться посилання — відкрийте його в браузері (зазвичай це `http://localhost:5173`).

---

## 📦 Інші команди

| Команда | Опис |
|---|---|
| `npm run dev` | Запуск локального сервера розробки |
| `npm run build` | Збірка проєкту для продакшну (папка `dist/`) |
| `npm run preview` | Попередній перегляд продакшн-збірки |
